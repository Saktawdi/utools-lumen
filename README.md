# Lumen · 流明

轻量的 uTools BYOK Agent 聊天插件。图片直接粘贴，模型自由切换，工具按需扩展。无需常驻服务。

> 0.1.0 Beta 预览版。uTools 快捷指令与 `.upxs` 离线安装流程仍待实机验收，尚未上架插件市场。

## 使用

在 uTools 搜索 **Lumen** 或 **流明** 打开。进入左下角「我的工作空间」添加供应商、API 地址和密钥；拉取模型后，勾选常用模型加入启动列表。在聊天顶部可切换任意启动模型。

- 图片支持粘贴、拖放、选图和 uTools 图片入口；文本及代码文件可作为附件。
- 模型支持复选、筛选全选、拖动框选（Shift 追加）和输入 ID 联想添加。
- 自动匹配 models.dev 的视觉、工具、上下文与推理参数；手动设置优先。可选推理强度，也可输入上游支持的值。
- OpenAI Chat、OpenAI Responses、Anthropic Messages、Google Gemini 四种协议。兼容网关应选择其实际实现的协议。
- 每个供应商、搜索服务均可批量导入多个密钥，去重、轮询和失败切换。
- AnySearch 官方 MCP、Tavily、SearXNG、自定义 JSON 搜索；配置页可测试连接。
- `list_tools`、时间、计算、网页搜索、网页读取、附件发现和读取；支持注册本地工具和 HTTP 工具。
- 输入框内单击切换「每次询问 / Auto」。默认对需授权工具逐次确认；Auto 自动允许，等待中的调用也会继续。模式会保留，关闭的工具仍不可执行。
- 浅色、深色、跟随系统；四款内置皮肤与 JSON 皮肤模块；紧凑布局及减少动态效果。
- 历史搜索、置顶、重命名、编辑重发、停止、重试、Markdown 导出和 JSON 备份恢复。

快捷键：`Ctrl+K` 搜索对话，`Ctrl+Shift+O` 新对话，`Ctrl+,` 打开设置，`Esc` 关闭浮层。发送方式可在设置中切换。

## uTools 快捷指令

| 指令       | 行为                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| AI翻译     | 选中文字后从超级面板选择，自动发送翻译；直接打开后粘贴文字也会发送。   |
| AI截图翻译 | 框选屏幕区域，截图复制到剪贴板并自动发送翻译；也支持 uTools 图片入口。 |
| AI问答     | 选中文字后自动咨询；直接打开后粘贴文字也会发送。                       |

设置 → 数据与偏好中指定「默认 Agent」和「翻译目标语言」。默认目标 `cn`（简体中文），也支持语言代码或自定义语言名称。快捷指令每次新建对话，不覆盖已有聊天。截图翻译需要支持图片的默认模型。聊天输入框也有「截图」按钮，截取后作为附件，按发送即可咨询。

## 本地安装

需要 uTools 8。在「uTools 开发者工具」中新建插件项目，选择「导入源码工程」，导入构建目录的 `plugin.json`，再「接入开发」并运行。若要生成 `.upxs`，请在 uTools 开发者工具中使用「构建离线安装包」；本仓库尚未发布 `.upxs` 或 uTools 市场版本。

工程中的 `release/lumen-0.1.0-local.zip` 是可解压导入的源码构建包。ZIP 内 `Lumen/plugin.json` 是导入入口。ZIP 无需 Node 环境，且不包含个人配置。

修改 preload 后，需要完全退出插件再打开。普通页面重载不能重新加载 Node 桥接。

## 开发

Node.js 22.12+：

```sh
npm ci
npm run dev
npm run check
npm run test:native
npm run package
```

`dev` 仅供浏览器开发，监听 `127.0.0.1:5178`；安装后的插件直接使用 preload，不依赖此服务。开发服务器默认使用当前用户的本地配置，隔离验证时请设定 `LUMEN_DATA_DIR`。

`test:native` 在 ESM 入口中加载实际构建的 preload，验证 CommonJS 模块边界、存储、权限模式和工具初始化；同时模拟宿主拒绝创建 Worker。`dist/package.json` 必须随插件保留，避免继承根工程的 ESM 模式。

结构：`src/` 界面与状态，`runtime/` 协议、网络、工具和加密存储，`scripts/` 构建与维护，`tests/` 核心回归。仓库中的 `docs/` 为本地开发文档，不属于公开项目。

## 数据

Windows 数据目录为 `%APPDATA%\uTools\lumen`。供应商、密钥与聊天使用 AES-256-GCM 存储，写入时保留上一版 `.bak`。`vault.key` 是本机解密密钥，也位于该目录；备份整个目录时需同时保存它。

JSON 备份默认不含供应商、搜索和 HTTP 工具的密钥或请求头。恢复这种备份会保留当前相同 ID 的密钥，并合并供应商和聊天。开启「导出时包含密钥」后，文件包含明文凭据。聊天内容本身会原样导出。

模型请求发送给选定供应商；搜索请求发送给配置的搜索服务；网页和 HTTP 工具发送给其目标地址。Lumen 不设置自己的遥测或中转服务。

更详细的数据处理说明见 [隐私说明](PRIVACY.md)。
