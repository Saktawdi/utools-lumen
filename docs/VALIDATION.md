# 验证记录

验证环境：Windows，uTools 8.0.1，开发者工具 2.7.0。功能先实现并运行，再开始 RSI；尚未确认的项目不计作通过。

## 已确认

- 本机 uTools 已接入开发并实际打开插件，界面、5 个供应商、启动模型与历史均由用户截图确认。
- 原 ChatGPT.好友 的 5 个自定义供应商已只读迁移；逐一核对名称、地址和每个密钥。拉取模型共 643 个，启动模型 8 个。原数据库未修改。迁移入口已按用户意见从产品移除。
- 真实 API 聊天与 Agent 计算调用，`(128+256)*3` 得到 `1152`。
- 真实视觉模型已读取工程图标；会话及图片在重新打开页面后保留。
- AnySearch 官方 MCP 真实搜索测试成功，返回 5 条结果；真实 Agent 已完成 `list_tools → web_search` 并返回官方文档链接。多密钥轮询使用 mock MCP 测试覆盖。
- 浏览器中快捷翻译实际发送给默认 Agent，`Hello, world!` 返回“你好，世界！”。进入翻译模式后粘贴 `Good morning.` 自动发送。
- 界面中实际拉取 107 个模型，筛选全选、复选、手动添加成功；`gpt-4o` 自动匹配到视觉、工具及 128K 上下文。手动覆盖不会被智能匹配清除。
- 四款皮肤切换更新强调色；深色与浅色 token 分别生效。
- 800 × 720 下输入框空白高度为 44px；移除装饰性页脚、英文口号及迁移提示。640 × 720 下侧栏折叠为图标，输入框无横向溢出。模型菜单层级和显示区域正常。
- 通过界面注册本地 HTTP 工具，真实 Agent 发起调用；界面等待确认，允许后本地服务收到参数并返回结果。
- `test:native` 从独立 ESM 进程加载实际 preload，验证 CommonJS 边界、存储、工具初始化、冷启动指令队列、截图复制和取消后窗口恢复（使用宿主 API mock）。
- 源码暂存检查没有包含本机真实凭据；本地配置、构建包及验证数据不进入 Git。

## 自动检查

`npm run check` 包括 TypeScript 和 Node 回归。覆盖 SSE 分块、4 协议图片与推理参数、工具上下文续接、密钥轮询/失败切换/取消、参数校验与审批、敏感错误隐藏、加密原子存储、Agent 工具循环、MCP 握手、模型目录匹配、无密钥备份恢复和无效导入原子失败。

前端与 runtime 模型匹配均有原厂优先、显式命名空间、未知模型和冲突元数据的回归。目录建立索引后复用；本机 8847 条目录首次索引约 34ms，500 次缓存匹配约 1ms，仅为单次本机测量。

## 字体与性能反馈修复（2026-10-24）

- 正文、消息输入统一 14px；小标签最低 11px，窄窗口也不再缩为 6–9px。改用稳定系统字体、原生文本渲染，提高辅助文字对比度，移除文本容器的缩放动画与弹窗背景模糊。空输入框在 800px 和 640px 宽度均保持 44px。
- 缓存未变化的消息、Markdown 和侧栏；仅在打开历史搜索时处理全文。消息编辑和重试读取当前对话及模型，避免缓存带来旧闭包。浏览器验证编辑回填正常。
- 支持时使用 CSS `field-sizing` 自动调整输入框，旧宿主保留 JS 回退，避免每次输入强制读取整页布局。
- 序列化、AES 加密和原子写入放入按需启动的 Node worker；空闲 15 秒释放。保留 LMN1 格式和备份，新增并发快照、旧数据读取、失败队列恢复回归。原生构建检查实际加载独立 worker 并保存、读回数据。
- 流式回答每 10 秒保存检查点，完成、停止和离开插件时保存；设置变化空闲 750ms 保存。强制终止进程可能丢失最近一次检查点后的生成片段。
- 同机浏览器开发模式、800 × 720、160 条消息及 120 个历史会话：39 次输入更新的 React Profiler 中位数由 25.5ms 降为 10.6ms，P95 由 140.2ms 降为 12.8ms。9.45MiB 合成快照，5 次保存调用同步占用由 72.1–91.2ms 降为 3.6–5.2ms；后者不代表磁盘写入完成时间。属于定向本机样本，不能等同所有设备的帧率或交互延迟。
- `npm run check`：26 项通过。临时计时入口已移除，不进入生产构建。800/640 宽度、明暗主题检查无聊天区横向溢出。
- uTools 本机菜单源码明确对 `plugin.isDev` 禁用固定到搜索框、超级面板、全局快捷键和别名；这是开发模式限制。待真实 `.upxs` 安装后复核。
